Academic Research

Geometric Knowledge Distillation (KD)

Working on neural model compression methods optimized for robotic edge devices.

Research Proposal: Geometric Representation Transfer

Dayananda Sagar University · Bangalore, India

Deep learning models often exceed the memory and compute capacity of edge robotic platforms, such as Raspberry Pi boards or micro-UAV controllers. While standard Knowledge Distillation (KD) transfers logits from a large "teacher" model to a lightweight "student" model, it fails to capture the underlying structural geometry of the representation space.

My research proposal focuses on Geometric Knowledge Distillation. By introducing manifold alignment, distance-preservation constraints, and topological mapping constraints, the transfer pipeline trains student networks that preserve the structural topology learned by teachers. This leads to higher model compression ratios while retaining high classification and navigation accuracy on low-power devices.

02_iterative_long_story_generation.ipynb View Notebook →

Working around hard context limits (1024 tokens in GPT-2) using an iterative sliding context window.

Mechanism

Chains model generation calls in a loop. In each loop, it extracts the last 150-200 generated tokens and feeds them back as the prompt context. Uses top-k and nucleus (top-p) sampling, and prevents repetition collapses.

Key Parameters

Sliding window: 150 - 200 tokens
Repetition limit: no_repeat_ngram_size = 3
Sampling: top_k = 50, top_p = 0.9

Story Progression Log

Step 1: Initial context generates paragraph 1 (tokens 0 - 200). Step 2: Slice tokens 50-200. Feed as prompt to generate paragraph 2 (tokens 200 - 400). Step 3: Repeat process. The model successfully generates a cohesive 1200+ word story without falling into repeating loops.

03_pytorch_simple_llm.ipynb View Notebook →

Building a simple N-gram language model from scratch in PyTorch without using pre-built library layers.

Mechanism

Maps a plain text corpus into a vocabulary index dictionary. Optimizes an embedding weights matrix directly against the training text sequence using Cross-Entropy Loss optimization.

Architecture Details

Inputs: word tokens translated to indices
Loss function: PyTorch nn.CrossEntropyLoss
Prediction: Autoregressive next-token index distribution

Model Class Definition Snippet

class SimpleNGramLM(nn.Module): def __init__(self, vocab_size, embedding_dim): super().__init__() self.embeddings = nn.Embedding(vocab_size, embedding_dim) self.linear = nn.Linear(embedding_dim, vocab_size) def forward(self, inputs): embeds = self.embeddings(inputs) out = self.linear(embeds) return out

04_numpy_self_attention.ipynb View Notebook →

Implementing the mathematical operations of scaled dot-product attention in pure NumPy.

Mechanism

Implements linear projections for Query, Key, and Value matrices. Performs matrix dot-product scaling, softmax scaling along columns, and multiplies by the Value matrix to compute self-attention.

Formula Implemented

Attention(Q, K, V) = softmax(Q @ K.T / sqrt(d_k)) @ V

NumPy Calculation Code

import numpy as np def self_attention(Q, K, V): d_k = Q.shape[-1] scores = np.matmul(Q, K.T) / np.sqrt(d_k) # Softmax along columns weights = np.exp(scores) / np.sum(np.exp(scores), axis=-1, keepdims=True) output = np.matmul(weights, V) return output, weights
