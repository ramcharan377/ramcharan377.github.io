Academic Research & Proposals

Geometric Knowledge Distillation for Edge Robotics

Deep learning models often exceed the runtime memory and compute capacity of lightweight robotic platforms. Standard knowledge distillation (KD) techniques map logit outputs from a teacher model to a student network but ignore the latent geometric manifold structure learned by intermediate representations.

My proposal introduces distance-preserving manifold alignment and topological mapping constraints into the distillation training pipeline. This ensures student networks maintain the structural topology of the teacher's latent space, enabling significant model compression while preserving navigation and control accuracy on edge devices like Raspberry Pi controllers.

03. Custom PyTorch N-gram Language Model

Autoregressive Scratch training | Model Architecture: Word embedding projection with Linear linear output layer

Maps a raw text corpus into a vocabulary vocabulary index dictionary, training cross-entropy predictions directly.

class SimpleNGramLM(nn.Module):
    def __init__(self, vocab_size, embedding_dim):
        super().__init__()
        self.embeddings = nn.Embedding(vocab_size, embedding_dim)
        self.linear = nn.Linear(embedding_dim, vocab_size)
        
    def forward(self, inputs):
        embeds = self.embeddings(inputs)
        return self.linear(embeds)

04. Raw NumPy Self-Attention Math

Attention Mechanism from scratch | Matrix shapes: (Sequence length, Dimension)

Implements scaled dot-product attention formula: softmax(Q @ K.T / sqrt(d_k)) @ V using raw matrices.

def self_attention(Q, K, V):
    d_k = Q.shape[-1]
    scores = np.matmul(Q, K.T) / np.sqrt(d_k)
    weights = np.exp(scores) / np.sum(np.exp(scores), axis=-1, keepdims=True)
    return np.matmul(weights, V), weights
