Research proposal

Geometric Knowledge Distillation

Methods for neural network compression targetting robotic hardware at the edge.

Geometric Representation Transfer Plan

Dayananda Sagar University · Bangalore, India

Standard knowledge distillation transfers classification probabilities from a large neural network (the teacher) to a smaller network (the student). While this compresses the model size, it fails to capture the rich geometric relationships and manifold structures present in the teacher's latent representation layers.

My research proposal focuses on Geometric Knowledge Distillation. By introducing distance-preservation constraints, manifold structure alignment, and topological mapping parameters, the training pipeline ensures the student network preserves the structural relationships between representations. This compression approach is designed for edge robotic controllers (e.g., Raspberry Pi systems and UAV microcomputers) where low latency and limited memory are critical.

03_pytorch_simple_llm.ipynb View Notebook →

Training an autoregressive word-level N-gram model on text data from scratch in PyTorch.

Mechanism

Maps character sequences to index dictionaries. Trains weight embeddings using Cross-Entropy Loss to output index probabilities.

Architecture Details

Inputs: vocabulary-indexed word tensors
Loss function: PyTorch nn.CrossEntropyLoss
Prediction: Autoregressive output prediction

Model Class Definition

class SimpleNGramLM(nn.Module): def __init__(self, vocab_size, embedding_dim): super().__init__() self.embeddings = nn.Embedding(vocab_size, embedding_dim) self.linear = nn.Linear(embedding_dim, vocab_size) def forward(self, inputs): embeds = self.embeddings(inputs) out = self.linear(embeds) return out

04_numpy_self_attention.ipynb View Notebook →

NumPy implementation of the scaled dot-product self-attention mechanism.

Mechanism

Multiplies input dimensions by query, key, and value weights. Applies softmax along row dimensions and scales outputs by dimension limits.

Attention Formula

Attention(Q, K, V) = softmax(Q @ K.T / sqrt(d_k)) @ V

NumPy Calculation Code

import numpy as np def self_attention(Q, K, V): d_k = Q.shape[-1] scores = np.matmul(Q, K.T) / np.sqrt(d_k) # Softmax along columns weights = np.exp(scores) / np.sum(np.exp(scores), axis=-1, keepdims=True) output = np.matmul(weights, V) return output, weights
