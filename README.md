# ramcharan377.github.io

A polished starter website for GitHub Pages.

## Local preview

Open `index.html` directly in a browser, or serve the folder with any static server.

## Publish to GitHub Pages

1. Push this folder to the `main` branch of `ramcharan377.github.io`.
2. In GitHub, open **Settings** > **Pages**.
3. Set the source to the `main` branch and the root folder.
4. Wait for the deployment link to appear.

## Customize

Replace the placeholder name, email, and section text in `index.html`.
